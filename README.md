# みんチャレ (min-challe)

小学生が、保護者に言われる前に自分から机に向かえるようになるための、ゲーミフィケーションを取り入れた家庭学習支援アプリケーションです。

バックエンドに **FastAPI (Python 3.12)**、フロントエンドに **React + TypeScript (Vite)** を採用したモダンな構成で開発されており、ログイン不要のデモ環境として **「おおの家」** ですぐにアプリの全機能を体験できます。

- **子どもユーザー**: ゆうき（小学3年生）
- **おうちの人ユーザー**: おうちの人
- **画面切り替え**: 画面上部のトグルで「こども」と「おうちの人」をシームレスに切り替え可能です。

---

## 🎯 アプリの目的

従来の家庭学習では、以下のような課題やストレスが家庭内で日常的に発生していました。

- 子どもが自分から勉強を始められず、保護者が毎日「勉強しなさい」と叱る必要がある。
- 子どもの毎日のドリルや宿題の丸付け・進捗チェックが、保護者の忙しい毎日の負担になる。
- がんばった成果や日々の小さな成長が、目に見える形で蓄積されないため継続しづらい。

「みんチャレ」は、これらの課題を解決し、**「子どもが自発的に計画を立てて学び、おうちの人が温かくそれを見守って褒める」** という新しい家庭学習の形（ポジティブな自習ループ）を実現することを目的としています。

---

## 🌱 アプリの意義（価値）

### ✔ 子ども（ゆうき）にとっての価値

- **やることが一目でわかる**: 今日やるべき計画が自分で確認できるため、迷わず勉強に取り組めます。
- **ゲーム感覚で続けられる**: ドリルをクリアするとポイントが貯まり、設定された「ごほうび」と交換できる楽しさがあります。
- **がんばりが蓄積される**: 自分が努力した軌跡が「アルバム」に残り、自信につながります。

### ✔ おうちの人にとっての価値

- **「勉強しなさい」を言わなくて済む**: 子どもが自ら計画を達成する仕組みが構築されるため、叱るストレスが減ります。
- **リアルタイムでがんばりが見える**: ドリルの正答率や計画の進捗状況が自動で可視化されます。
- **「認める・ほめる」に集中できる**: アルバムへの短い思い出メモの記録や、「できたことをほめる」機能（できたねスタンプ・カスタムルールでポイントを手動付与）を通じて、ポジティブな親子コミュニケーションが生まれます。

## 🧩 機能一覧（4本柱）

本アプリは、子どもが自主的に学習を続けられるように設計された4つの連動するコア機能から成り立っています。

### 1. 📅 けいかく管理

- **子ども**: 今日と今週の予定を確認し、終わったら「できた！」をワンタップで記録する。
- **おうちの人**: 毎日の予定の追加、修正、削除、進捗の確認。

### 2. ✍️ ドリル学習

子どもの理解度や段階に合わせて挑戦できる学習ドリルです。

| 分野 | 種類 | 概要 |
| --- | --- | --- |
| さんすう | たしざん / ひきざん / かけざん / わりざん | 10問。レベル1〜100（5回全問正解でレベルアップ）。レベル40以降は最後2問が文章題 |
| こくご | かんじのよみ / じゅくごのよみ | 10問。ひらがな入力。漢字・熟語バンク |
| こくご | おはなしのどくかい | 1話＋3問（4択・解説）。90話バンク。ステージ1〜6。各話に fact / reason / learning の3問 |
| しゃかい | とどうふけん / にほんのちり / ちずきごう / けんのかたち | 10問（4択）。地図・記号画像あり。ステージ1〜6 |
| りか | いきもののせいかつ / じしゃくとでんき / たいようとかげ / ひかりとおと / てんきとみず | 10問（4択）。ステージ1〜6（学年成長型）。`image_url` 対応 |

- その場で ○× フィードバック、履歴の保存
- 全問正解ボーナス（家庭ルールに応じてポイント）

### 3. 🪙 ポイントシステム

- **子ども**: 計画の達成やドリルクリアで獲得したポイントを使って、あらかじめ設定された「ごほうび」と交換する。
- **おうちの人**: ポイント追加ルールの設定、ごほうびの登録、「できたことをほめる」機能（できたねスタンプ・カスタムルールによる手動付与）。

### 4. 📸 アルバム記録

- **子ども**: 自分がやりきった「できた！」の記録を一覧で確認する。
- **おうちの人**: 子どものがんばりに対する短い褒め言葉や、成長の思い出メッセージを記録・共有する。

## 🛠 技術スタック

### バックエンド (Backend)

- **言語/ランタイム**: Python 3.12（※3.14 などの最新すぎるバージョンは非推奨）
- **フレームワーク**: FastAPI, Uvicorn
- **データ**: SQLAlchemy（SQLite）
- **テスト**: pytest
- **日本語処理**: pykakasi（ドリル自動ルビ生成）

### フロントエンド (Frontend)

- **言語/ランタイム**: Node.js 22, TypeScript
- **フレームワーク/ビルドツール**: React, Vite
- **UI**: Tailwind CSS, Lucide React（アイコン）

### データ

- SQLite（`backend/data/minchalle.db`）
- 国語バンク（`backend/data/kokugo/`）
- 読解原稿（`dokkai_stories.json` → `dokkai.json`）
- 社会バンク・地図 SVG（`frontend/public/shakai/`）

## 📥 開発環境の構築と起動方法

ブラウザは **フロント** を開きます（`http://127.0.0.1:48221`）。  
`/api` はバックエンド（`http://127.0.0.1:48222`）へプロキシされます。

> **注意**: `--reload` は使わないでください。コードを変えたら API を再起動します。  
> スキーマやバンクを大きく変えたときは `backend/data/minchalle.db` を削除してから再起動してください。

### 前提条件

- **Python 3.12** がインストールされていること。
- **Node.js 22** がインストールされていること。

Windows で `python` がストア案内になる場合は `py -3.12` を使います。

---

### バックエンドの起動

#### Windows (PowerShell)

```powershell
cd backend
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 48222
```

#### macOS / Linux

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 48222
```

---

### フロントエンドの起動（別のターミナル）

```bash
cd frontend
npm install
npm run dev
```

開発用サーバーは `http://127.0.0.1:48221` で立ち上がります。API へのリクエストは自動的に 48222 ポートへプロキシされます。
