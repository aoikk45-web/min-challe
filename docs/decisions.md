# decisions.md — 判断記録

> 状態: **L0 で仕様承認済み。** デモ学年は 3 年に確定。

## D1. FastAPI + React（Vite）+ SQLite

- 採用: ユーザー指定の FastAPI＋React。MVP 速度のため SQLite。
- 却下: Next.js フルスタック（指定スタックから外れる）、PostgreSQL（この環境で追加サービスが要る）。

## D2. 認証なしのロール切替

- 採用: `role=child|parent` でデモ家庭を切替。
- 却下: JWT / 世帯招待。1 週間 MVP の範囲外。後から世帯ログインを載せる余地は API を `/api` に閉じることで残す。

## D3. ポイント計算はサーバ側

- 採用: ルール表をサーバが読み、付与する。フロントは表示と操作だけ。
- 理由: 家庭ルールを子どもが改ざんできないようにする。

## D4. アルバムはテキスト＋スタンプ

- 採用: 自動エントリと保護者メモ。
- 却下: 画像アップロード（ストレージと安全面を MVP に持ち込まない）。
