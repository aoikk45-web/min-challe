# ドリル問題作成のゴールデンルール

小学3年生向け家庭学習ドリルの **問題文・例文** を書くときの正本。  
国語・社会・理科など、科目を問わず適用する。

AI が問題を生成・修正するときは、この文書に従う。

## 1. 語彙と表現

- 小学3年生が日常的に使う、親しみやすく自然な日本語を使う。
- 直訳調を避ける（例: 「〜を持っています」「〜によって作られました」）。
  自然な動作・状態の表現にする（例: 「〜があります」「〜でできています」）。
- 漢字は小学3年生までに習う範囲を基本とする。4年生以上の漢字、およびバンク未登録の漢字にはふりがなを付ける。
- **熟語**は漢字を切らず、語全体のあとに読みを付ける（例: `準備(じゅんび)`、`洗濯物(せんたくもの)`）。
- **送り仮名がある動詞・形容詞**は、漢字の読み部分だけをカッコに書く（`終(お)わる`、`座(すわ)って`）。訓読みを使う。
- カタカナ語、小学1〜2年生の簡単な漢字（`日` `風` `手` など）にはルビを付けない。
- ふりがな付与は `backend/app/kokugo_kanji.py` が実行時に行う。`scripts/build_dokkai_bank.py` で未付与の高学年漢字がないか検証する。

## 2. 国語（かんじ・じゅくご・短文）

- 例文は子どもの日常生活（学校・家庭・遊び・動物など）に身近な場面にする。
- 不自然に漢字を詰め込んだ短文は禁止。
- 存在しない熟語、意味が通らない suffix テンプレ（「〜の字をおぼえます」など）は使わない。
- 読みが複数ある漢字は、文脈で一意に読めるようにする。

## 3. 社会・理科など

- 専門用語を並べるだけの問題文にしない。
- 小学生の視点で「不思議に思うこと」「身近な発見」をベースにする。
- 正解が暗記の羅列にならないよう、ひとこと説明や場面を添える。

## 4. おはなしの読解（`おはなしのどくかい`）

**技術・データ形式・ふりがな・採点の詳細は [dokkai.md](dokkai.md) が正本。**

- 90話の本文・設問は **[NotebookLM](https://notebooklm.google.com/)** で作成し、`dokkai_stories.json` に取り込んだ（出所の詳細は [dokkai.md](dokkai.md)）。

- 主人公は **ゆうき**（小学3年生）。1話あたり本文 250〜350字（ステージ1-2はやや短く、5-6はやや長くてよい）。
- 設問は3問固定: ①事実（`fact`）②理由・行動（`reason`）③学び・気持ち（`learning`）。すべて4択＋小学生向け解説。
- 直訳調を避け、児童書のような自然な日本語にする。
- 前向きなテーマ（協力、観察、お手伝い、宿題への挑戦など）にする。
- ステージ1〜6で難易度を分ける（社会ドリルと同型）。90話（各ステージ15話）。
- 原稿は **ふりがななしのプレーンテキスト**。`correct` は `choices` のいずれかと完全一致。正解は本文から読み取れること。
- 選択肢は原稿では1番目に正解を置いてよい（出題時にシャッフル）。
- **ルビ生成**（`kokugo_kanji.py` が実行時に自動適用）:
  - **熟語**は漢字を切らず語全体のあとに読み（`準備(じゅんび)` `一緒(いっしょ)`）。
  - **送り仮名**は漢字の読み部分だけ（`座(すわ)って` `終(お)わる`）。訓読み。音読み禁止。
  - カタカナ語、小学1〜2年生の簡単な漢字にはルビなし。
  - `引っ張る` 系は `引っ張(はっぱ)って`（`引` はルビなし、`張` に `はっぱ`）。
- 原稿正本: `backend/data/kokugo/dokkai_stories.json`。検証・ビルドは [dokkai.md](dokkai.md) 参照。
- ふりがなの期待例: ステージ1 `s1_03`「ねことの午後」（`test_neko_no_gogo_passage_furigana`）。

## 5. 生成後のセルフチェック

問題を追加・変更したら、次を確認する。

1. 声に出して読んで、不自然な日本語がないか
2. 小学3年生が意味を取れる語彙か
3. 正解が文脈から自然に導けるか
4. 似た問題のコピペ感・テンプレ感が強くないか
