# ドリル問題作成のゴールデンルール

小学3年生向け家庭学習ドリルの **問題文・例文** を書くときの正本。  
国語・社会・理科など、科目を問わず適用する。

AI が問題を生成・修正するときは、この文書に従う。

## 1. 語彙と表現

- 小学3年生が日常的に使う、親しみやすく自然な日本語を使う。
- 直訳調を避ける（例: 「〜を持っています」「〜によって作られました」）。
  自然な動作・状態の表現にする（例: 「〜があります」「〜でできています」）。
- 漢字は小学3年生までに習う範囲にとどめる。難しい語はひらがなで書く。
  ルビが振れない画面では、特にひらがなを優先する。

## 2. 国語（かんじ・じゅくご・短文）

- 例文は子どもの日常生活（学校・家庭・遊び・動物など）に身近な場面にする。
- 不自然に漢字を詰め込んだ短文は禁止。
- 存在しない熟語、意味が通らない suffix テンプレ（「〜の字をおぼえます」など）は使わない。
- 読みが複数ある漢字は、文脈で一意に読めるようにする。

## 3. 社会・理科など

- 専門用語を並べるだけの問題文にしない。
- 小学生の視点で「不思議に思うこと」「身近な発見」をベースにする。
- 正解が暗記の羅列にならないよう、ひとこと説明や場面を添える。

## 4. 生成後のセルフチェック

問題を追加・変更したら、次を確認する。

1. 声に出して読んで、不自然な日本語がないか
2. 小学3年生が意味を取れる語彙か
3. 正解が文脈から自然に導けるか
4. 似た問題のコピペ感・テンプレ感が強くないか
