## このループの完了条件

- アプリが起動する
- さくら家 / みんすけ **3年生** / おかあさん が見える
- 「こども ⇄ おうちの人」を切り替えられる
- 4本柱の入口がある（中身の機能は次ループ。空状態でよい）

## やらないこと

## 状態の意味

| 状態 | AI | 人間 |
| --- | --- | --- |
| `waiting-A` | 提案まで。実装禁止 | 範囲を GO / 差し戻し |
| `implementing` | 承認済み範囲のみ実装 | 待ってよい |

| `stopped` | 何もしない | 再開指示を出す |
