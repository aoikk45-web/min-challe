# requirements.md — MVP 要件

> 状態: **草案**。プロダクトの正本候補は [spec.md](./spec.md)。ここは箇条書きの控え。

## プロダクト

**みんチャレ** — 小学生が「自分でやってみよう」と思える家庭学習アプリ。  
保護者はルールだけ整え、子どもが努力を見て、残せる。

対象: 小学 1〜6 年。MVP のデモ家庭は 2 年生の子ども 1 人。

## 非目標（MVP に入れない）

- 弱点分析・自動個別最適
- 本格ログイン / OAuth / 複数家庭の本番運用
- 課金、広告、SNS 共有
- 漢字・国語・英語ドリル
- 写真アップロード（成長アルバムはテキストとスタンプで十分）

## 4本柱

### 1. 学習計画

子どもが「今日なにをすればいいか」を自分で分かる。

- 保護者は週の計画（科目・内容・目安）を登録・編集・削除できる。
- 子どもは今日/今週の計画を大きなカードで見て、完了ボタンを押せる。
- 完了すると計画が済みになり、家庭ルールに従ってポイントが付く。
- 空の週は「まだ予定がないよ。おうちの人につくってもらおう」と出す。

### 2. 計算ドリル

楽しく、すぐ結果が分かり、自分からもう一回やりたくなる。

- たしざん / ひきざん / かけざん / わりざん。
- 学年（1〜6）で数字の桁と範囲が変わる。
- 1回 10 問。その場で ○×。終わりに得点・かかった時間。
- 全問正解は特別に祝う。
- 履歴は子どもにも保護者にも見える。

### 3. ポイント制（家庭ごとに設定可能）

努力の可視化。ポイントの意味は家庭が決める。

- 保護者は付与ルールを自由に設定できる。
  - 例: ドリル 1 回 = 10pt、全問正解ボーナス = 5pt、計画完了 = 8pt、できたねスタンプ = 3pt
  - ルールの ON/OFF、点数の変更、新規ルール追加、削除。
- 保護者は交換できるごほうびを設定できる（必要な点数・名前）。
- 子どもは残高・履歴・次のごほうびまでのバーを見る。
- 子どもはごほうびと交換できる（残高不足なら理由を出す）。
- 保護者は「できたねスタンプ」で任意ポイントを渡せる。

### 4. 成長アルバム

できたことを残し、後から見返して自信にする。

- ドリル完了・計画完了・ごほうび交換・スタンプは自動でアルバムに載る。
- 保護者は短い思い出メモを追加できる。
- タイムラインは新しい順。スタンプ絵文字で種類が分かる。
- 件数 0 のときは「最初のページは、これからつくられるよ」と出す。

## 共通 UX

- 子どもモード / おうちの人モードをホームから切り替えられる（MVP は認証なし、デモ家庭固定）。
- 子ども画面は大きなボタン、ひらがな多め、明るい色。
- 空・読込・エラーの 3 状態を主要画面で扱う。
- デスクトップとスマホ（保護者が横で見る / 子どもがタブレット）の両方で使える。

## 受け入れ（MVP Done）

1. デモ家庭ですぐ触れる。
2. 4本柱が画面として繋がり、ポイントが計画・ドリル・スタンプから実際に増える。
3. 保護者がルールをごほうびを変えると、子どもの画面に反映される。
4. README からローカル起動できる。
