問題文の文体は [drill-prompt-rules.md](drill-prompt-rules.md) §3 と併用する。

| 項目 | 内容 |
| --- | --- |
| ループ | L14 |

## 種類（2種・MVP）

### `いきもののせいかつ`

小学3年の観察単元を中心とする（**5年の「メダカの雌雄」などは出題しない**）。

| テーマ例 | 出題例 |
| --- | --- |
| 昆虫のからだ | 「昆虫（こんちゅう）の足は、からだのどの部分から生えている？」→ むね（4択） |
| 植物の育ち方 | 「ヒマワリの種（たね）から最初に出てくるのは？」→ 根（ね）（4択） |
| 秋の生き物 | 「まつむしの なきごえを きく 季節は？」→ あき（4択） |

### `じしゃくとでんき`

小学3年の「電気の通り道」「磁石の性質」。

| テーマ例 | 出題例 |
| --- | --- |
| 電気の通り道 | 「電気を通す（明かりがつく）ものはどれ？」→ 鉄のハサミ（4択） |
| 磁石 | 「じしゃくに つく ものはどれ？」→ くぎ（4択） |
| N極・S極 | 図あり問題も可（`image_url` 参照） |

## ステージ設計（学年成長型・案A）

理科は小学3年から始まる教科のため、ステージと学年の対応を **明示** する（社会ドリルのテーマ別ラベルとは別定義）。

| ステージ | 対応学年 | ラベル（UI） |
| --- | --- | --- |
| 1〜2 | 小学3年 | ゆうきのいま / 3年生のふつう |
| 3 | 小学4年 | 4年生の範囲 |
| 4 | 小学5年 | 5年生の範囲 |
| 5〜6 | 小学6年 | 6年生のふつう / 6年生のチャレンジ |

実装では `step` から **出題可能な最大学年 `max_grade`** を次のように決める:

```
step 1,2 → max_grade 3
step 3   → max_grade 4
step 4   → max_grade 5
step 5,6 → max_grade 6
```

バンク JSON の各問に `grade`（3〜6）を付け、現在ステージの `max_grade` 以下の問だけから10問を選ぶ。

各種 **学年3〜6年** ごとに **15問以上** を収録。`scripts/merge_rika_bank.py` で `rika_bank_data.py` の追加問題をマージできる。

| 種別 | 合計 | 小3 | 小4 | 小5 | 小6 |

| いきもののせいかつ | 78 | 23 | 19 | 18 | 18 |

#### いきもののせいかつ（学習内容の対応）

| 学年 | 主な単元 |
| --- | --- |
| 3年 | 昆虫の体、植物の芽・成長、秋の生物 |
| 4年 | 花のつくりと受粉、植物の体、動物の生き方 |
| 5年 | メダカの誕生と育ち、人体のつくり、植物の体 |
| 6年 | 生物と環境、生態系、生物の多様性 |

#### じしゃくとでんき（学習内容の対応）

| 学年 | 主な単元 |
| --- | --- |
| 3年 | 電気の通り道、磁石の性質 |
| 4年 | 電気回路（直列・並列）、コンパス、電磁石の基礎 |
| 5年 | 発電のしくみ、電気の利用、電磁石 |
| 6年 | 交流と直流、再生可能エネルギー、安全な電気の使い方 |

## 形式

- 社会ドリルと同型: **4択ボタン**、`choices` / `correct` / ひらがな正規化採点
- **`image_url: string | null` を標準装備**（社会と同一スキーマ・同一 UI コンポーネント）
  - L14 初版は画像なし（`null`）でも可
  - 回路図・磁石の N/S 図などは `frontend/public/rika/` に SVG/PNG を置き、後から追加しやすくする
- ポイント・アルバムは既存 `drill_complete` / `drill_perfect` をそのまま利用

## データ形式（案）

`backend/data/rika/{kind}.json` — 配列:

```json
{
  "prompt": "昆虫（こんちゅう）の足は、からだのどの部分から生えている？",
  "choices": ["あたま", "むね", "はら", "しっぽ"],
  "correct": "むね",
  "grade": 3,
  "kind": "いきもののせいかつ",
  "image": null
}
```

- `image`: ファイル名または ID。API では `/shakai/...` と同様に `image_url` へ変換（例: `/rika/circuits/bulb_series.svg`）
