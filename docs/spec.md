## 1. なにを作るか

小学生が、保護者に言われる前に **自分から机に向かえる** 家庭学習アプリ。

保護者は「勉強しなさい」を増やすのではなく、

- 今日やること（学習計画）
- 楽しく反復できる場（ドリル）
- 家庭ごとのごほうびルール（ポイント制）
- できた記録（成長アルバム）

の4つを軸に整える。あわせて、毎日のおやくそく・ミニゲーム・簡易 PIN で「続けやすさ」と「おうちの人だけの設定」を支える。

仮名: **みんチャレ**

| 項目 | 前提 |
| --- | --- |
| 対象 | 小学 1〜6 年（デモは 3 年生） |
| デモ家庭 | **おおの家** / 子ども「**ゆうき**」3年生 / 保護者「**おうちの人**」 |
| 同時利用 | 1家庭・子ども1人 |
| 認証 | 起動 PIN とおうちの人 PIN（4桁）。本格ログイン・複数家庭は後回し |
| 技術 | FastAPI + React（Vite） |

## 2. だれが、なにをするか

```
おうちの人                         子ども（ゆうき）
  │                                  │
  │ 今週の計画を置く                  │ 今日のカードを見てやる
  │ ルール・ごほうび・やくそくを決める │ ドリル・おうえん・ゲーム
  │ できたねスタンプを押す             │ ポイントとアルバムを見る
  │ アルバムに一言残す                 │ ごほうびと交換する
```

### 子ども

- 今日の計画が大きなカードで分かる。
- ドリルを自分で選んで始め、すぐ ○× が分かる。進みが遅い種類は「おうえんドリル」から入れる。
- ミニゲームで遊べる（クリアでポイント可・家庭ルール次第）。
- 毎日のおやくそくをチェックする。
- ポイント残高と「次のごほうびまで」が見える。
- 成長アルバムで「前よりできた」を見返せる。

### おうちの人（保護者）

- 計画・ポイントルール・ごほうび・おやくそくを家庭のやり方に合わせて変える。
- 勉強以外の努力にも「できたねスタンプ」で点を付けられる。
- 子どもの履歴とアルバムを見られる。
- おうちの人モードへの切替・設定変更にはおうちの人 PIN が必要。

ポイントの意味（何点で何と交換するか）はアプリが決めない。**家庭が決める。**

## 3. 入れるもの / 入れないもの

### 入れる（4本柱＋周辺）

1. 学習計画
2. ドリル学習（さんすう・こくご・りか・しゃかい・えいご）
3. ポイント制（家庭ごとに設定可能。ごほうびの1日上限あり）
4. 成長アルバム
5. 毎日のおやくそく
6. ミニゲームコーナー（クリア時ポイントは家庭ルール）
7. 起動 PIN / おうちの人 PIN

柱どうしはつながる。計画完了・ドリル完了・ミニゲームクリアなどでポイントが付き、それがアルバムに残る。

### 入れない（後回し）

- 弱点分析、ミス率に基づく自動出題最適化（おうえんは学年めやすとの進度差）
- 本格ログイン、複数家庭、子どもが複数人
- 漢字の書き取り（手書き・IME）。次に足すなら読み→漢字4択
- 写真アップロード、SNS、課金、オンライン対戦
- 理科の未実装単元（ものの燃え方・てこ・月と星など）

## 4. 4本柱の仕様

### 4.1 学習計画

目的: 子どもが「今日なにをすればいいか」を自分で分かる。

| できること | だれ |
| --- | --- |
| 日付・科目・内容・目安分の計画を追加・直す・消す | おうちの人 |
| 今日と今週の一覧を見る | 両方 |
| 「できた」を押して完了にする | 子ども（おうちの人も可） |

完了すると、その家庭のルールに従ってポイントが付き、アルバムに1件残る。

計画が無い週は「まだ予定がないよ。おうちの人につくってもらおう」と出す。無理な自動生成はしない。

### 4.2 ドリル学習

目的: 短時間で終わって、すぐ結果が分かり、もう一回やりたくなる。

画面上は **教科カード**（さんすう・こくご・りか・しゃかい・えいご）から単元を選ぶ。

| 分野 | 種類 | 概要 |
| --- | --- | --- |
| さんすう | たしざん / ひきざん / かけざん / わりざん | 10問。レベル1〜100（全問正解5回連続で+1）。レベル40以降は最後2問が文章題。わりざんは割り切れる問題のみ |
| こくご | かんじのよみ / じゅくごのよみ | 10問。ひらがな入力。レベル1〜100（算数と同型）。レベル40以降は最後2問が文章題 |
| こくご | おはなしのどくかい | 1話＋3問（4択・解説）。ステージ1〜6。各話 fact / reason / learning |
| しゃかい | とどうふけん / にほんのちり / ちずきごう / けんのかたち | 10問（4択）。地図・記号画像あり。ステージ1〜6 |
| りか | いきもののせいかつ / じしゃくとでんき / たいようとかげ / ひかりとおと / てんきとみず | 10問（4択）。ステージ1〜6。`image_url` 対応 |
| えいご | たんご / あいさつ | 10問（4択）。ステージ1〜6。結果で正解英語をタップすると Web Speech（`en-US`）で読み上げ。採点は大文字小文字無視 |

共通:

- その場 ○×。終わりに正解数とかかった時間。全問正解は祝う（ボーナスは家庭ルール）
- こくごのよみはカタカナ・空白をひらがなにそろえて採点。書き取りはやらない
- 履歴は一覧で見られる

**おうえんドリル（L21）:** 子どもの学年に対するめやす進度より遅れている種類（なければ相対的に遅い種類）を子ども画面に示し、タップでその種類を開始できる。ミス率は使わない。ポイント・ステージ規則は変えない。

### 4.3 ポイント制（家庭設定）

目的: 努力が見える。点数の価値は家庭が決める。

おうちの人が変えられるもの:

1. **付与ルール**（何をしたら何点か）  
   例:
   - ドリルを1回やりきる → 10pt
   - 全問正解ボーナス → 5pt
   - 計画を1つ完了 → 8pt
   - ミニゲームクリア → 5pt（既定・無効化可）
   - できたねスタンプ → 3pt  
   点数の変更、ON/OFF、ルールの追加・削除ができる。
2. **ごほうび**（何点で何と交換するか）  
   例: ゲーム15分 = 30pt、好きなおやつ = 50pt  
   **1日上限**（件数）を設定できる。上限に達したごほうびはその日は交換できない（L17）。
3. **できたねスタンプ**  
   勉強以外（片付け、音読の姿勢など）にも点を付けられる。

子ども側:

- いまの残高
- 履歴（いつ、なぜ増減したか）
- 次のごほうびまでのバー
- 残高が足りればごほうびと交換（足りなければ「あと○点」）

ごほうび交換は即時に点を減らす。おうちの人の再承認フローは後回し。  
ポイント計算はサーバ側。子どもが画面から点数を書き換えられない。

### 4.4 成長アルバム

目的: できたことを残し、見返して自信にする。

自動で残るもの:

- 計画をやりきった
- ドリルをやりきった
- ごほうびと交換した
- できたねスタンプ

おうちの人は短い思い出メモを足せる。写真は後回し。  
新しい順のタイムライン。種類はスタンプ絵文字で区別する。  
1件も無いときは「最初のページは、これからつくられるよ」。

## 5. 周辺機能

### 5.1 毎日のおやくそく（L18）

- 家庭で決めた毎日のやくそく項目を子どもがチェックする。
- 未達分はルールに応じてポイントが減ることがある（おうちの人が設定）。
- 下部ナビ「やくそく」／ホームからも入る。

### 5.2 ミニゲームコーナー（L22）

- 子ども向けあそび。ブラウザ完結。オンライン対戦・課金なし。
- 例: カップゲーム、しんけいすいじゃく、インベーダー、ブロックくずし、くるまレース。
- クリア時は付与ルール `game_clear`（表示名「ミニゲームクリア」）に従いポイント付与。
- ドリルの学習データ・ステージ規則は変えない。

### 5.3 ログイン PIN（L19）

- **起動 PIN**: アプリを開くとき。
- **おうちの人 PIN**: 「おうちの人」モードへの切替・PIN 変更など。
- どちらも 4 桁の数字。ハッシュで保存。本格認証・OAuth は後回し。

## 6. 画面の大枠

下部ナビ（7入口）:

| 画面 | 子ども | おうちの人 |
| --- | --- | --- |
| ホーム | 今日の計画、残高、各入口 | 同じ概要 |
| けいかく | 今週を見て「できた」 | 追加・編集・削除 |
| ドリル | 教科・種類を選んで挑戦。おうえん | 履歴を見る |
| ゲーム | ミニゲーム | あそび（ポイントはルール設定） |
| やくそく | 毎日チェック | 項目と減点の設定 |
| ポイント | 残高・バー・交換 | ルールとごほうびの設定、スタンプ |
| アルバム | タイムライン | メモ追加 |

ヘッダーで「こども ⇄ おうちの人」を切り替える（おうちの人側は PIN）。

子ども向けの見た目: 大きなボタン、ひらがな多め、明るい色、短い言葉（「できたね」「もういっかい」）。  
主要画面は、空 / 読み込み中 / 失敗 の3状態を出す。

## 7. いちばん大事な流れ（つながり）

```
おうちの人が計画・ルール・やくそくを置く
        │
        ▼
子どもが計画 / ドリル / やくそく / ゲームをやる
        │
        ├─→ ポイントが増減する（家庭の点数）
        │         │
        │         └─→ ごほうびと交換 → ポイントが減る（1日上限あり）
        │
        └─→ アルバムに残る（計画・ドリル・交換・スタンプ）
```

「やった → 点が付く → 残る → ごほうびが見える」が一本の体験であること。

## 8. デモで最初から入っているもの

触った瞬間に空に見えないようにする。

- 家庭名: おおの家（ゆうき・おうちの人）
- 今週の計画が数件（過去日は済み、今日以降は未完了）
- 付与ルール（ミニゲームクリア含む）とごほうびの初期値
- ポイント残高とアルバムが数件

初期値はおうちの人画面から全部変えられる。  
体験をやり直すときは `backend/scripts/reset_demo.py`（[README](../README.md) 参照）。

## 9. できあがり条件（受け入れ）

1. デモ家庭ですぐ触れる（初回は PIN 設定、以降は起動 PIN）。
2. 子どもが計画完了とドリル完了をすると、ポイントが増え、アルバムに残る。
3. おうちの人がルールやごほうびを変えると、子どもの画面に反映される。
4. 下部ナビから各入口に行ける。
5. ローカルで README どおりに起動できる。
