# みんチャレ 大まかな仕様（MVP）

> 状態: **承認済み（2026-08-28）**。プロダクト仕様の正本。  
> 変更: デモ子どもは **みんすけ 3年生**。詳細設計はループごとに足す。

---

## 1. なにを作るか

小学生が、保護者に言われる前に **自分から机に向かえる** 家庭学習アプリ。

保護者は「勉強しなさい」を増やすのではなく、

- 今日やること（学習計画）
- 楽しく反復できる場（計算ドリル）
- 家庭ごとのごほうびルール（ポイント制）
- できた記録（成長アルバム）

の4つを整える。子どもは努力が見え、残るので、もう一回やりたくなる。

仮名: **みんチャレ**（変更可）

| 項目 | MVP の前提 |
| --- | --- |
| 対象 | 小学 1〜6 年 |
| デモ家庭 | さくら家 / 子ども「みんすけ」3年生 / 保護者「おかあさん」 |
| 同時利用 | 1家庭・子ども1人 |
| 認証 | なし。画面上で「こども」と「おうちの人」を切り替える |
| 技術 | FastAPI + React（指定） |

---

## 2. だれが、なにをするか

```
保護者                         子ども
  │                              │
  │ 今週の計画を置く              │ 今日のカードを見てやる
  │ ポイントルールをごほうびを決める │ ドリルを10問やる
  │ できたねスタンプを押す         │ ポイントとアルバムを見る
  │ アルバムに一言残す             │ ごほうびと交換する
```

### 子ども

- 今日の計画が大きなカードで分かる。
- 計算ドリルを自分で選んで始め、すぐ ○× が分かる。
- ポイント残高と「次のごほうびまで」が見える。
- 成長アルバムで「前よりできた」を見返せる。

### 保護者

- 計画・ポイントルール・ごほうびを家庭のやり方に合わせて変える。
- 勉強以外の努力にも「できたねスタンプ」で点を付けられる。
- 子どもの履歴とアルバムを見られる。

ポイントの意味（何点で何と交換するか）はアプリが決めない。**家庭が決める。**

---

## 3. MVP に入れるもの / 入れないもの

### 入れる（4本柱）

1. 学習計画
2. 計算ドリル
3. ポイント制（家庭ごとに設定可能）
4. 成長アルバム

柱どうしはつながる。計画完了やドリル完了でポイントが付き、それがアルバムに残る。

### 入れない（後回し）

- 弱点分析、自動で難しい問題を出す
- 本格ログイン、複数家庭、子どもが複数人
- 漢字・国語・英語
- 写真アップロード、SNS、課金、対戦

---

## 4. 4本柱の仕様

### 4.1 学習計画

目的: 子どもが「今日なにをすればいいか」を自分で分かる。

| できること | だれ |
| --- | --- |
| 日付・科目・内容・目安分の計画を追加・直す・消す | 保護者 |
| 今日と今週の一覧を見る | 両方 |
| 「できた」を押して完了にする | 子ども（保護者も可） |

完了すると、その家庭のルールに従ってポイントが付き、アルバムに1件残る。

計画が無い週は「まだ予定がないよ。おうちの人につくってもらおう」と出す。無理な自動生成はしない。

### 4.2 計算ドリル

目的: 短時間で終わって、すぐ結果が分かり、もう一回やりたくなる。

| 項目 | MVP |
| --- | --- |
| 種類 | さんすう: 4種。こくご: 2種。**L12 案:** しゃかい: とどうふけん / にほんのちり / ちずきごう / けんのかたち（4択・地図・記号画像あり） |
| 1回 | 10問。さんすうはレベル40以降、最後の2問が文章題 |
| さんすうの段階 | 種類ごとにレベル1〜100。10問全問正解が5回連続でレベル+1 |
| こくご | 種類ごとにレベル1〜100。レベル40以降は最後2問が文章題。漢字1026字・熟語356語のバンク |
| わりざん | 割り切れる問題だけ |
| その場 | ○×。終わったら正解数とかかった時間 |
| 全問正解 | 特別に祝う（ボーナスポイントは家庭ルール次第） |

こくごはひらがなでよみを入れる。カタカナはひらがなにそろえて採点する。書き取り（手書き・IME）はやらない。

履歴は一覧で見られる。解説AIや弱点マップは作らない。

### 4.3 ポイント制（家庭設定）

目的: 努力が見える。点数の価値は家庭が決める。

保護者が変えられるもの:

1. **付与ルール**（何をしたら何点か）  
   例:
   - ドリルを1回やりきる → 10pt
   - 全問正解ボーナス → 5pt
   - 計画を1つ完了 → 8pt
   - できたねスタンプ → 3pt  
   点数の変更、ON/OFF、ルールの追加・削除ができる。
2. **ごほうび**（何点で何と交換するか）  
   例: ゲーム15分 = 30pt、好きなおやつ = 50pt
3. **できたねスタンプ**  
   勉強以外（片付け、音読の姿勢など）にも点を付けられる。

子ども側:

- いまの残高
- 履歴（いつ、なぜ増減したか）
- 次のごほうびまでのバー
- 残高が足りればごほうびと交換（足りなければ「あと○点」）

MVP のごほうび交換は即時に点を減らす。保護者の再承認フローは後回し。  
ポイント計算はサーバ側。子どもが画面から点数を書き換えられない。

### 4.4 成長アルバム

目的: できたことを残し、見返して自信にする。

自動で残るもの:

- 計画をやりきった
- ドリルをやりきった
- ごほうびと交換した
- できたねスタンプ

保護者は短い思い出メモを足せる。写真は後回し。  
新しい順のタイムライン。種類はスタンプ絵文字で区別する。  
1件も無いときは「最初のページは、これからつくられるよ」。

## 5. 画面の大枠

子どもは下部の大きな4つの入口。保護者は同じ場所に「編集」が増える。

| 画面 | 子ども | 保護者 |
| --- | --- | --- |
| ホーム | 今日の計画、残高、ドリルへ | 同じ概要 |
| 計画 | 今週を見て「できた」 | 追加・編集・削除 |
| ドリル | 種類を選んで10問 | 履歴を見る |
| ポイント | 残高・バー・交換 | ルールとごほうびの設定、スタンプ |
| アルバム | タイムライン | メモ追加 |

ヘッダーで「こども ⇄ おうちの人」を切り替える。

子ども向けの見た目: 大きなボタン、ひらがな多め、明るい色、短い言葉（「できたね」「もういっかい」）。  
主要画面は、空 / 読み込み中 / 失敗 の3状態を出す。

## 6. いちばん大事な流れ（つながり）

```
保護者が計画とルールを置く
        │
        ▼
子どもが計画をやる / ドリルをやる
        │
        ├─→ ポイントが増える（家庭の点数）
        │         │
        │         └─→ ごほうびと交換 → ポイントが減る
        │
        └─→ アルバムに残る
```

4本柱がバラバラの機能に見えてはいけない。  
「やった → 点が付く → 残る → ごほうびが見える」が一本の体験。

---

## 7. デモで最初から入っているもの

触った瞬間に空に見えないようにする。

- 家庭名: さくら家
- 今週の計画が数件（過去日は済み、今日以降は未完了）
- 付与ルールとごほうびの初期値
- ポイント残高とアルバムが数件

初期値は保護者画面から全部変えられる。

---

## 8. MVP のできあがり条件

1. デモ家庭ですぐ触れる（ログイン作業なし）。
2. 子どもが計画完了とドリル完了をすると、ポイントが増え、アルバムに残る。
3. 保護者がルールやごほうびを変えると、子どもの画面に反映される。
4. 4つの入口から4本柱に行ける。
5. ローカルで README どおりに起動できる。

---

## 9. あとから足すもの（仕様に含めない）

弱点分析、出題の個別最適、複数子ども、本格ログイン、写真、他教科。  
今回の大まかな仕様の範囲外。承認後の実装ループでも勝手に入れない。
